# Dew heater guide

Dew forms on the secondary mirror when the mirror cools below the dew point. On Gull Point this
happens on most nights between September and April.

## Procedure

1. Plug the heater strap into port DH-2 on the controller, never DH-1, which is reserved for the
   finder scope.
2. Set the controller to 40 percent output at the start of the session.
3. If the humidity reading passes 85 percent, raise the output to 70 percent.
4. Switch the heater off before closing the dome so the strap does not cook the baffle tube.

## Part numbers

The replacement heater strap is part ZX-4471. The controller's spare fuse is part ZX-0090, a
2-amp slow-blow fuse.
